# Mutual Fund Recommendation & Risk Analytics Dashboard

Built an ML-inspired recommendation engine using
fund performance, alpha, beta, Sharpe ratio,
drawdown and expense metrics.

## Features

- Risk-based fund recommendations
- Alpha/Beta analytics
- Sharpe ratio analysis
- SIP inflow dashboard
- Category inflow visualization
- Interactive Streamlit dashboard

## Tech Stack

Python
Pandas
NumPy
Scikit-Learn
Plotly
Streamlit
SQLite (future integration)
